# YGO TYPE — 遊戲王卡圖自動拼接器

這個工具根據使用者輸入的中文文字，透過 [百鴿（YGOCDB）API](https://ygocdb.com/api) 搜尋**卡名含有指定字元**的卡片，從每張卡片的卡名位置裁出一條圖片，按字序自動拼在一起。

## 如何啟動

**推薦方式（搜尋與圖片匯出較可靠）**：安裝 Python 3 後，Windows 雙擊 `start_windows.bat`；macOS / Linux 執行 `bash start_mac_linux.sh`。工具會開啟 `http://127.0.0.1:8765`，不需安裝額外的 Python 套件。需要網路連線下載百鴿卡片資料與圖片；下載內容會快取於 `.cache`。

**免安裝**：[開啟公開網頁](https://gs040664.github.io/ygo-type-auto-stitch/)。直接開啟新版 `index.html` 時也會讀取公開版的卡名索引。

## 功能

- 輸入最多 24 個字元。搜尋共用卡名索引，並平行載入各字的卡圖。
- 預設首字須位在第一張卡的卡名開頭，尾字須位在最後一張卡的卡名結尾。兩項可獨立放寬。
- 預設整張成品使用同一版本，選擇能匹配最多字元的版本。同分依日文 OCG、簡中 OCG、英文 TCG 排序。取消同一版本限制後可逐字選用不同版本。
- 每張卡依該語言的卡名匹配字元及裁切位置。同版本卡圖的字體或字色仍可能隨卡種與印刷版本而異。手動上傳會另標示為自選圖。開啟同一版本並關閉「優先使用不同卡片」時，會優先使用能提供最多字元的同一張卡。
- 可依序換卡、左右微調裁切，或上傳自己的圖。支援等寬切片、首尾加寬、匯出解析度與接縫顯示。
- 可下載成品 PNG，或在支援圖片剪貼簿的瀏覽器直接複製。缺圖位置會在成品中標示。

## 限制

- 可辨識的日文與漢字卡名依卡圖上的字形裁切，切片保留卡圖比例。混排、特殊字型或異圖可能需要依估算位置逐字微調。
- 百鴿的卡圖 API 提供日文、簡中與英文。需要繁中實卡圖時，可逐字上傳。
- 公開版卡圖依賴百鴿 CDN 及 [wsrv.nl](https://wsrv.nl/docs/) 的圖片轉送，讀取失敗時可改用本機版或上傳圖片。
- Python 服務只監聽本機 `127.0.0.1`，並限制卡片 ID 與語言。

## GitHub Pages 網頁版部署

[部署工作流程](.github/workflows/deploy-pages.yml)從百鴿公開資料包擷取卡名與 ID，產生 `card-names.json`，與 `index.html` 一起部署。Pages 設定的部署來源須為 GitHub Actions。本機版從同一份資料包建立索引，並由 Python 服務代理卡圖。
